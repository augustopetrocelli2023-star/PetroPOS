# PetroPOS Professional 1.0 RC - Build 009

## Cambios principales

- Caja mejorada con arqueo al cierre y diferencia esperada/contada.
- Reportes con filtro por rango de fechas.
- Reporte de ventas por hora y por medio de pago.
- Configuración ampliada del negocio, ticket, lector, Point y backups.
- Ticket de prueba desde Configuración y Centro Técnico.
- Detección de impresoras desde Electron.
- Centro Técnico mejorado con tamaño de base, diagnóstico de impresoras y auditoría.
- Se mantiene la corrección del POS para ventas consecutivas y campos desbloqueados.

## Pruebas sugeridas

1. Abrir caja con saldo inicial.
2. Hacer una venta.
3. Cerrar caja ingresando efectivo contado.
4. Ver diferencia de caja.
5. Generar ticket de prueba.
6. Ver impresoras detectadas.
7. Filtrar reportes por fecha.
