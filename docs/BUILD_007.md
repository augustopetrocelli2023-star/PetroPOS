# PetroPOS Professional 1.0 RC Build 007

## Cambios principales

- Clientes profesional: alta, edición, búsqueda, DNI/CUIT, contacto, saldo y observaciones.
- Proveedores profesional: alta, edición, búsqueda, datos fiscales, contacto y observaciones.
- Ticket mejorado: formato 58/80 mm, datos fiscales, cliente, cajero, subtotales, descuento, recibido y vuelto.
- Reportes ampliados: ganancia estimada, ticket promedio, medios de pago, productos más vendidos y stock bajo.
- Exportación CSV ampliada para clientes y proveedores.
- Se mantiene corregido PP-006: campos del POS desbloqueados después de ventas consecutivas.

## Pruebas sugeridas

1. Crear cliente nuevo y seleccionarlo en venta.
2. Hacer venta y revisar ticket TXT.
3. Editar proveedor.
4. Ver reportes y exportar CSV.
5. Confirmar que búsqueda/descuento/recibido siguen funcionando después de cobrar.
