# PetroPOS Professional 1.0 RC Build 004

Cambios principales:

- Nuevo módulo Compras / ingreso rápido de mercadería.
- Actualización automática de stock al registrar compras.
- Kardex básico con movimientos por venta, compra y ajuste manual.
- Dashboard con productos más vendidos.
- Reportes ampliados con compras.
- Versión actualizada a Build 004.

Pruebas sugeridas:

1. Abrir caja.
2. Registrar una compra de un producto.
3. Verificar que suba el stock.
4. Hacer una venta.
5. Verificar que baje el stock.
6. Revisar Stock > Kardex.
