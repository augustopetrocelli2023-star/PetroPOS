# PetroPOS Professional 1.0 RC - Build 010

## Cambios principales

- Módulo Tickets agregado.
- Reimpresión de tickets desde historial y con F8.
- Anulación de ventas con devolución automática de stock.
- Devoluciones totales con movimiento de caja y stock.
- Reportes excluyen ventas anuladas.
- Ticket marca ventas anuladas/devoluciones cuando corresponde.
- Auditoría de anulaciones, devoluciones y reimpresiones.

## Pruebas sugeridas

1. Vender un producto.
2. Reimprimir el ticket desde Tickets.
3. Anular una venta desde usuario administrador.
4. Confirmar que el stock vuelve.
5. Confirmar que Reportes no suma la venta anulada.
6. Registrar una devolución y revisar Caja/Stock.
